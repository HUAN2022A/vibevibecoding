# 全球 AI 应用盈利案例知识库

收集全球范围内 **AI 应用/产品如何赚钱** 的真实案例，记录收入、定价、成本结构、增长引擎与护城河，用于后续做产品、写报告或做数据分析。

> 数据基准日：**2026-09-14**。所有数字都标注了「时点 + 来源 + 可信度」，请勿脱离时点引用。

## 目录结构

```text
docs/ai-monetization/
├── README.md                  # 本文件：总览、字段规范、使用方法
├── cases/                     # 案例卡片（按赛道分文件）
│   ├── foundation-models-and-assistants.md
│   ├── consumer-apps.md
│   ├── dev-tools.md
│   ├── creative-media.md
│   ├── vertical-enterprise.md
│   └── indie-bootstrapped.md
├── patterns.md                # 盈利模式归纳 + 反直觉结论 + 风险清单
├── advice.md                  # 创业建议（行动指南 + 可行性自检表）
├── sources.md                 # 来源清单、可信度分级、待核实项
└── data/
    └── cases.csv              # 结构化数据，便于筛选取数/接入产品
```

**当前规模**：24 个公司/产品案例，6 大板块，`cases.csv` 共 28 条记录（含子产品与同一创作者的多条产品线）。

## 案例卡片字段规范

| 字段 | 说明 |
| --- | --- |
| 赛道 | 基础模型 / 消费应用 / 开发工具 / 创意媒体 / 垂直行业 / 独立开发者 |
| 客户类型 | B2C / B2B / B2B2C / 开发者 |
| 收入模式 | 订阅 / 用量计量 / 座位制 / 按结果 / 广告 / 授权 / 混合 |
| 收入数字 | 同时记录「金额」和「口径」（ARR / 年化 / 自然年确认收入 / 单季度）+ 时点 |
| 增长 | YoY 增速、里程碑达成速度（如 $1M→$500M ARR 用时） |
| 定价 | 具体档位与价格 |
| 成本结构 | 推理/GPU 成本占比、毛利率、是否亏损 |
| 估值与融资 | 最新估值 + 时点、累计融资额 |
| 增长引擎 | 分销合作 / PLG / 企业销售 / 生态与联盟 / 病毒传播 |
| 护城河 | 数据、独家内容授权、工作流嵌入、分发渠道、合规资质 |
| 关键洞察 | 这条案例最值得学的一点 |
| 可信度 | A=公司披露或审计口径，B=权威媒体/研究机构估算，C=媒体转述或估算，D=存疑/冲突 |

## 可信度分级说明

- **A**：公司官方披露、财报、监管文件
- **B**：Sacra / Business of Apps / Reuters / Bloomberg 等机构估算或引用
- **C**：二手转述、单一来源、无法交叉验证
- **D**：不同来源互相矛盾，或存在明显口径问题 — **引用前必须复核**

## 使用方式

- 想找创业方向 / 做立项决策 → 直接读 `advice.md`
- 想看模式与结论 → 直接读 `patterns.md`
- 想按某个公司查 → 在 `cases/` 里找，或 `grep` 公司名
- 想拿数据做分析/做产品 → 用 `data/cases.csv`
- 想引用某个数字 → 先在 `sources.md` 确认可信度等级

## 重要免责说明

1. **私募公司收入数字基本都不是审计口径**。同一家公司在不同来源下可能差 2-5 倍，原因包括：ARR vs 年化 vs 确认收入、gross vs net 记账、是否含云转售、是否含一次性授权费。
2. **本知识库不追求「唯一正确答案」**，而是保留分歧，标注口径。冲突数字一律并列展示。
3. 已知存在明显冲突或需复核的项，集中记录在 `sources.md` 的「待核实清单」。
