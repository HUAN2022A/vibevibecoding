# 案例：垂直行业与企业级

覆盖 Harvey（法律）、Abridge（医疗文书）、OpenEvidence（医疗决策）、Glean（企业搜索）、Clay（销售 GTM）、Sierra（客服）、Perplexity（AI 搜索）。

**这一赛道是本知识库中「最接近真实盈利」的部分**，共同特征：垂直数据/资质护城河 + 高客单 + 净收入留存驱动扩张。

---

## Harvey（法律）

| 项 | 内容 |
| --- | --- |
| 客户类型 | B2B（大型律所 + 企业法务） |
| 收入模式 | **座位制**（seat-based） |
| 收入 | ARR **$350M**（2026-07）；2025 年底 $195M；YoY **+290%**<br>2025-08 突破 $100M ARR（成立约 3 年） |
| 客户规模 | **142,000+ 律师**，1,500+ 客户，60+ 国家，含 **50% 的 Am Law 100** 和 50 家资管机构 |
| 使用量 | 周活同比增 4 倍，月查询量增 5.5 倍，活跃文件 975 万 |
| 扩张机制 | 账号通常从几百个席位起步；**内部数据显示席位中位数在 12 个月内翻倍**；针对保险/金融的行业模块与文档管理系统集成抬高了平均合同额 |
| 估值 / 融资 | 估值 **$15.5B**（2026-09 growth round $550M）<br>路径：2025-02 $3B → 2025-06 $5B → 2025-12 $8B → 2026-03 $11B → 2026-09 $15.5B<br>累计融资 >$1.2B |
| 产品转型 | **放弃了自研垂直法律模型**——因为 Google、xAI、OpenAI、Anthropic 的前沿模型在 Harvey 自家的 BigLaw Bench 上跑赢了它。转为围绕「预配置 agent 工作流 + 多模型路由」定位 |
| 规模 | 500+ 用例 agent，日执行 70 万+ 任务，周提取 5,000 万+ 条款；客户自建 25,000+ 自定义 agent |
| 内容护城河 | 与 LexisNexis 战略联盟（Ask LexisNexis：基于美国联邦/州判例、成文法、行政法规、Shepard's Citations 的带引用回答） |
| 关键洞察 | **垂直 AI 公司不应该自研垂直模型。** Harvey 主动砍掉自研模型，承认前沿实验室的通用模型更好，把自己重新定位成「工作流 + 数据 + 内容授权 + 合规」的整合层。这是整个 AI 应用层最重要的一条战略结论：**应用层的护城河不在模型，而在工作流嵌入与专有内容**。 |
| 可信度 | B |

## Abridge（医疗文书）

| 项 | 内容 |
| --- | --- |
| 客户类型 | B2B（医疗系统） |
| 收入模式 | 企业订阅许可，**按临床医生数或就诊量计价** |
| 收入 | ARR **$100M**（2025-05），2024 年底 $60M；2025 Q1 合同 ARR 达 $117M |
| 定价 | 约 **$2,500 / 临床医生 / 年**（竞品 Nabla $119/月、Nuance DAX Copilot $600/月） |
| 客户 | Kaiser Permanente（24,600 名医生、40 家医院、600 家诊所）、Mayo Clinic（2,000+ 医生）、Johns Hopkins、Duke Health、UPMC、Yale New Haven 等 90+ 公开客户 |
| 估值 / 融资 | 估值 **$5.3B**（2025-06 Series E $300M，a16z 领投）；2025-02 为 $2.75B；2026-04 追加 $316M |
| 分发护城河 | 成为**首个官方集成进 Epic EHR** 的环境 AI 工具（"Pal" 项目）；**给 Epic 股权 + 持续收入分成**，换取对使用 Epic 的 38% 医院网络的优先接入，领先竞品 3-6 个月集成深度 |
| 关键洞察 | **在医疗这种超高信任门槛的行业，「接入权」比「产品好」更值钱。** Abridge 把股权和分成让给 Epic，换来了在 Mayo、Kaiser、Duke 的默认地位。代价也很明确：它基本放弃了去颠覆 Epic 的可能，被锁在自己的渠道伙伴生态里。 |
| 可信度 | B |

## OpenEvidence（医疗决策支持）

| 项 | 内容 |
| --- | --- |
| 客户类型 | B2B2C（免费给医生 + 企业版给医疗系统） |
| 收入模式 | **医药/器械广告**（CPM 计价）+ 企业订阅 + API 授权 |
| 收入 | 年化 **$300M**（2026-07）；2025 年底 $150M；**2024 年仅 $7.9M**（两年增约 38 倍） |
| 毛利率 | **约 90%** |
| 关键单位经济 | 广告 **CPM $70-$1,000+**，对比社交媒体普遍的 $5-15；**ARPU 约 $124** |
| 使用量 | 月约 2,000 万次临床咨询；2026-03-10 单日 **100 万次**；每月 6.5 万+ 新认证医生注册 |
| 分发规模 | 覆盖 **40%+ 美国医生**，10,000+ 医院与医疗中心；Sutter Health、Mount Sinai（7 家医院）、Cedars-Sinai 已全院部署并嵌入 Epic |
| 内容护城河 | **独家内容授权**：NEJM、JAMA、Wiley 生物医学文献、Cochrane 系统综述、美国心脏病学会、美国糖尿病协会、NCCN 肿瘤学算法、AUA 泌尿指南 |
| 估值 / 融资 | 估值 **$12B**（2026-01 Series D $250M）；近一年累计融资近 $700M<br>估值路径：$3.5B（2025-07）→ $6.1B（2025-10）→ $12B（2026-01） |
| 对标 | 对比竞品：UpToDate（Wolters Kluwer）按 $500/seat 向医院收费、年收入 $595M；Doximity 年收入 $570M（80% 来自广告，ARPU $228） |
| 关键洞察 | **「免费」是最强的渠道策略。** 医疗行业的销售周期约 18 个月，OpenEvidence 直接绕开：免费给医生用、不碰病历（后通过 HIPAA BAA 合规化），先把渗透率做到 40%，再以此为筹码向上攻医院企业合同。而且它选择了一个 **CPM 比社交媒体高 100 倍的广告市场**（药企面向医生的精准投放），证明「广告模式在 AI 里能不能成立」取决于你是否处在一个本来就很贵的广告市场。 |
| 可信度 | B |

## Glean（企业搜索 / AI 中间层）

| 项 | 内容 |
| --- | --- |
| 客户类型 | B2B（中端市场 + 企业，500+ 员工） |
| 收入模式 | **按座位订阅** |
| 收入 | ARR **$300M**（2026-05），2025 年底 $208M；YoY **+89%**<br>2025-01 破 $100M → 2025-12 达 $200M（9 个月翻倍） |
| 合同规模 | 典型首年合同 **$100K-$500K**；Fortune 500 客户可 **>$5M/年**<br>$1M+ 合同段在此期间近 3 倍增长，全公司部署翻倍以上 |
| 销售周期 | 企业 4-5 个月；1,000 人以下中端市场 90 天 |
| 估值 / 融资 | 估值 **$7.2B**（2025-06 Series F $150M，Wellington 领投）；2024-09 为 $4.6B；累计融资约 $768M |
| 使用量 | Glean Agents 年支撑 **1 亿+ agent 动作**，年 token 处理量超 **20 万亿**；Assistant 每活跃日平均被使用 6 次 |
| 定位转型 | 从「企业搜索」重定位为**企业 AI 中间层**：多模型抽象 + 深度集成（自研 Enterprise Graph）+ 权限感知治理层 |
| 关键洞察 | **企业 AI 的付费点不是「更聪明」，而是「不泄露数据」。** Glean 的核心价值是权限感知的治理层与引用溯源——它让企业敢把 AI 接到内部系统上。同时主打「模型中立」（同时接入 Bedrock / Vertex / Azure），避免被单一模型厂商卡脖子。 |
| 可信度 | B |

## Clay（销售 GTM 自动化）

| 项 | 内容 |
| --- | --- |
| 客户类型 | B2B（GTM / 销售 / 市场团队） |
| 收入模式 | 订阅 + 用量计量（**双计量**） |
| 收入 | ARR **$150M**（2026-05），2025 年底 $108M；YoY **+260%** |
| 定价机制演进 | 2026-03 从「单一 credit 模型」改为 **Data Credits + Actions 双计量**：Data Credits 支付第三方数据增强与 AI/数据成本；Actions 计量工作流执行步骤（HTTP 调用、CRM 同步、AI 任务、序列发送等）<br>改动后：多数原生增强成本下降 **50-90%**，失败查询不再收费，CRM 同步/HTTP API/Web Intent 从 $800 Pro 档下移到新的 **$495 Growth 档** |
| 毛利特征 | 旧模型含数据转售成本，毛利更像数据型 SaaS；转向 Actions 计量后，把低毛利的增强收入与高毛利的编排收入分离，混合毛利应逐步改善 |
| 估值 / 融资 | 估值 **$7.1B**（2026-09 Series D $115M）<br>路径：$500M（2024-06）→ $1.25B → $1.5B → $3.1B（2025-08）→ $5B（2026-01）→ $7.1B<br>累计融资至少 $202M 一级股权 |
| 关键洞察 | **计量单位的重新设计就能直接改善毛利。** Clay 把「卖数据」和「卖编排」拆成两个计价表，让客户自带 API key 时公司仍能对编排收费。这是一个非常可复用的小技巧：**当你的成本结构和价值创造发生在不同环节时，用一个计价表一定会算错账。** |
| 可信度 | B |

## Sierra（AI 客服）

| 项 | 内容 |
| --- | --- |
| 客户类型 | B2B（中端到大型企业） |
| 收入模式 | **按对话量 或 按成功解决结果（pay-per-resolution）** |
| 收入 | ARR **$200M**（2026-05）；2025 年底约 $130M；**2024 年底仅 $26M**；YoY **+400%** |
| 里程碑速度 | 2023 年成立，2024-02 上线；**2025-11 破 $100M ARR（上线后第 7 个季度）**，随后出现首个 $50M 季度 |
| 客户规模 | 覆盖 **40% 的 Fortune 50**；客户含 WeightWatchers、SiriusXM、Sonos、ADT、Chime、Cigna、Nordstrom、Nubank、Ramp、Rivian、Rocket Mortgage、Singtel、Sutter Health、Wayfair |
| 渠道变化 | **语音渠道在 2025-10 之前就已超过文本**成为主要交互渠道（而美国客服约 80% 的交互原本发生在电话上） |
| 能力 | 可执行真实后端动作：退款、开工单、收银行卡与 ACH 付款；首家 Level 1 PCI 合规的对话式 AI，可在单次会话中完成收款/续费/购买 |
| 估值 / 融资 | 估值 **$15.8B**（2026-05 Series E $950M，GV + Tiger Global 领投）；2025-09 为 $10B；2024-10 为 $4.5B；累计融资 $1.585B |
| 关键洞察 | **按结果收费是 AI 客服唯一说得通的模式。** 客户不关心你用了什么模型，只关心问题有没有解决。Sierra 把定价与「成功解决」绑定，等于把 AI 的不确定性风险从客户转移给自己——这反而让它敢要高价。这也解释了 79× 的估值/ARR 倍数（$15.8B / $200M）。 |
| 可信度 | B |

## Perplexity（AI 搜索）—— 主动放弃广告的反例

| 项 | 内容 |
| --- | --- |
| 客户类型 | B2C + 企业 + 政府 |
| 收入模式 | 订阅 + 用量层（agent credits）+ 分销合作 + 商务导流 |
| 收入 | 年化 **$750M**（2026-08）；2025 年底 $232M；YoY **+268%**；2025 年收入增长 4.7× |
| 用户 | 100M+ MAU，数万家企业客户 |
| 定价 | Free（限量）/ Pro $20/月 / Max $200/月（含 10,000 credits/月，上线时一次性赠 20,000）/ Enterprise Pro $40/seat/月 |
| 关键决策 | **主动放弃广告变现**，理由是广告会损害用户对 AI 回答的信任（与 OpenAI、OpenEvidence 的选择正好相反） |
| 分销引擎 | Motorola 全球预装（Razr/Edge 60 新机捆绑 3 个月 Pro）<br>Bharti Airtel：3.6 亿用户免费获 12 个月 Pro（2025-07 起，2026-01 停止新兑换）——免费期结束后印度 IAP 与订阅收入在 2026-02 至 8 月中增长约 **60%**<br>Snap $400M 合作（2026 起接入 Snapchat）<br>美国 GSA 合同：联邦机构可按 **$0.25/机构**采购 Enterprise Pro for Government（18 个月） |
| 其他变现 | PayPal/Venmo 合作（站内直接购物、订票、订酒店）；Getty 图片多年授权 |
| 估值 / 融资 | 估值 **$20B**（2025-09 Series E $200M）；累计融资约 $1.5B |
| 关键洞察 | **大规模免费发放是可以转化为付费的，但要用对地区。** Airtel 案例显示：3.6 亿人免费用一年后，印度付费收入在免费期结束的半年内涨约 60%。这是「补贴换习惯、习惯换付费」在 AI 里少见的可验证证据。<br>另外，Perplexity 明确拒绝广告，说明**「AI + 广告」不是普适解**——OpenEvidence 能成立是因为它处在 CPM $70-1000 的医药广告市场，而通用搜索的广告价值不足以补偿信任损失。 |
| 可信度 | B |
