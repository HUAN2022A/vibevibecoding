# 案例：开发工具

覆盖 Cursor、Claude Code、GitHub Copilot、Codex。这是目前**单位经济最健康**的 AI 赛道之一。

## Cursor（Anysphere）

| 项 | 内容 |
| --- | --- |
| 赛道 | 开发工具（AI-native IDE） |
| 客户类型 | 个人开发者 → 企业 |
| 收入模式 | 订阅分层（Free / Pro / Business / Ultra / 企业） |
| 收入 | 年化 **$4B**（2026-05）；2025 年底为 $1.2B（突破 $1B ARR 的时点为 2025-12） |
| 增长 | YoY **+1,100%**；被 Sacra 称为**从 $1M 到 $500M ARR 增长最快的 SaaS 公司**，收入约每两个月翻倍 |
| 收入结构 | 大型企业客户占 **约 60%**（已从早期个人开发者订阅转向企业） |
| 定价 | Free / Pro $20/月 / Business $40/user/月 / Ultra $200/月（20× Pro 用量）/ 企业定制 |
| 单位经济 | 2026-04 起**实现小幅毛利率转正**（靠自研 Composer 模型 + 更便宜的模型路由）<br>⚠️ 关键细节：**大型企业账号毛利为正，个人开发者账号仍然亏损** |
| 客户规模 | 50,000+ 工程团队；约 70% Fortune 1000 在用（NVIDIA、Uber、Adobe、Salesforce、PwC） |
| 估值 / 融资 | 2026-06-16 SpaceX 签署以 **$60B 收购**（2026 Q3 完成）<br>此前 2025-11 Series D $2.3B at $29.3B；估值路径 $400M → $2.5B → $9.9B → $29.3B → $60B |
| 增长引擎 | PLG（开发者自发使用）→ 企业上收；跨 IDE 扩展（JetBrains 通过 ACP）；云 agent + 移动端 |
| 护城河 | 上下文与 agent 编排能力 + 自研低延迟模型 + 多模型伙伴关系 + 企业安全审查产品 |
| 关键洞察 | **这是「个人亏损、企业赚钱」最清晰的一个样本。** Cursor 没有对所有用户涨价，而是让企业客户为个人用户的算力买单。做 AI 应用时，如果你的重度个人用户成本高于其订阅费，唯一出路是把企业当作毛利来源，而不是指望个人端跑正。 |
| 可信度 | A/B |

| 项 | 内容 |
| --- | --- |
| 赛道 | 开发工具（CLI + 原生 Mac app） |
| 收入模式 | 包含在 ChatGPT Plus/Pro/Business/Enterprise 订阅中；API 计费 |

## 开发工具赛道的共性结论

1. **按座位收费仍然有效**，因为企业愿意为每个工程师付固定费用，预算审批路径成熟。
2. **毛利与模型选择强相关**。Cursor 转向自研 Composer + 便宜模型路由后才接近毛利转正；纯调用第三方前沿模型的工具毛利会被吃掉。
3. **PLG → 企业上收**是标准路径：先让个人开发者免费用起来（甚至亏钱），再让企业 IT 买单。
4. **增速天花板极高但窗口期极短**。Cursor 从 $1M 到 $500M ARR 是史无前例的速度，同时也意味着竞争者追赶速度同样快。
