# 案例：基础模型与通用助手

覆盖 OpenAI、Anthropic、xAI、Google Gemini、Microsoft Copilot、DeepSeek。

---

## OpenAI（ChatGPT）

| 项 | 内容 |
| --- | --- |
| 赛道 | 基础模型 + 通用助手 |
| 客户类型 | B2C + B2B + 开发者 |
| 收入模式 | 订阅 + API 用量 + 广告 + 授权（混合） |
| 收入 | 年化 **$40B**（2026-07，口径：年化收入，不含微软授权收入与大额一次性交易）<br>单季 $6.7B（2026 Q2，Q1 为 $5.7B）<br>2025 年底年化为 $20B |
| 增长 | YoY **+233%**；2026 Q3 至今整体 run rate +35%，企业收入 run rate +50% |
| 收入结构 | 企业占比 **>50%**；API 估计占总收入 **15-20%**；广告业务 2026-08 年化达 **$1B** |
| 定价 | Plus $20/月、Pro $200/月、Team 约 $25-30/seat/月、Enterprise 牌价约 $60/seat<br>印度专属 ChatGPT Go $5/月 |
| 成本结构 | 毛利率 **33%**，被推理成本压制（推理成本 2025 $8.4B → 2026 预计 $14.1B）<br>预计现金消耗 2026 约 $27B、2027 约 $63B；**2030 年才现金流转正** |
| 估值 / 融资 | 估值 **$852B**（2026-03-31 关闭 $122B 轮，SoftBank 联合领投）<br>2026-06-08 秘密提交 IPO，目标估值 **>$1T**；累计融资约 $219.7B |
| 用户 | 1B+ 月活 app 用户、900M+ 周活（全端）；2026-02 消费者订阅 **50M**、企业付费用户 **>9M** |
| 增长引擎 | 消费者订阅为主 + 企业座位扩张 + API 生态（Notion/Salesforce/Bing 等内嵌）+ 广告 |
| 护城河 | 模型能力 + 品牌 + 企业分发 + 自建算力（Stargate / 自研推理芯片 Jalapeño） |
| 关键洞察 | **规模最大 ≠ 最赚钱**：毛利率仅 33%，且要到 2030 才转正。它靠资本市场融资支撑补贴式增长，是「用钱换份额」的极致形态。同时把广告作为第三收入曲线，且只在 Free/Go 层放广告，保住付费层的干净体验。 |
| 可信度 | A/B（Sacra 估算 + 公司披露混合） |

**另一个口径（Business of Apps）**：OpenAI 估值 $730B（2026-02）；ChatGPT 2025 年为 OpenAI 贡献 **$8B**，约占公司总收入 66%（2023 $1.2B → 2024 $3.5B → 2025 $8B）。

> ⚠️ 两个口径的「收入」不可直接比较：Sacra 用年化收入（run-rate），BoA 用自然年贡献口径。

## Anthropic（Claude）

| 项 | 内容 |
| --- | --- |
| 赛道 | 基础模型 + 通用助手 |
| 客户类型 | B2B 为主 + B2C |
| 收入模式 | API 按 token 用量 + 企业合同 + 消费者订阅 |
| 收入（口径冲突，见下） | **Sacra**：年化 $65B（2026-07），2026-05 为 $47B<br>**Business of Apps**：Anthropic 2025 年收入 $6B；其中 Claude 产品线 $1.25B（2024 $0.105B） |
| 收入结构 | 企业 + API 占比 **55-80%**（两来源不一致）；Claude Code 占 20%；Claude Pro 占 20% |
| Claude Code | 2025-11 年化 $1B → **2026-02 年化 $2.5B**；企业占其收入一半以上 |
| 客户规模 | 300,000+ 企业客户（2025-10）贡献约 80% 收入；1,000+ 客户年花费 >$1M（2026-04），两年前仅十几家；Fortune 10 中有 8 家在用 |
| 定价 | Opus 4.7：$5 / $25 per M tokens（长上下文 $10/$37.50）<br>Sonnet 4.5：$3 / $15 per M tokens<br>Fable 5：$10 / $50 per M tokens |
| 估值 / 融资 | Sacra 记录估值 $965B（2026，$65B Series H 后），累计融资约 $125B<br>Business of Apps 记录估值约 $350B（2025-11）、累计融资 $41.5B |
| 用户 | Claude 消费者端约 20M（2025）；下载量仅 20M+（远低于通用助手） |
| 增长引擎 | 企业销售 + 云市场分销（AWS Bedrock / Google Vertex / Microsoft Foundry）+ 开发者口碑 |
| 护城河 | 编码与企业任务上的模型口碑、MCP 开放标准带来的集成锁定、云厂商分销 |
| 关键洞察 | **用户数不是关键，ARPU 才是**。Claude 消费者用户只有 ChatGPT 的 1/50，但收入结构里企业占绝对主导，靠的是高价值任务（编码、法律、金融）和座位/用量扩张。 |
| 可信度 | **D（存在重大口径冲突）** |

> ⚠️ **必须复核**：Sacra 称 Anthropic 从 2025 年底约 $6B 跳到 2026-07 的 $65B 年化，7 个月内增长约 10 倍，与 Business of Apps 的 $6B（2025 自然年）差距极大。同时「$65B Series H」与「$65B ARR」两个数字在 Sacra 页面内混用，存在把融资额与 ARR 混淆的可能。**引用前务必回源核实。**
>
> ⚠️ Sacra 明确指出：Anthropic 对云转售收入按 **gross 口径**记账（把终端客户总支出计为收入，把伙伴分成计为费用），这会系统性抬高其收入与其他 net 口径公司不可比。

## xAI（Grok）

| 项 | 内容 |
| --- | --- |
| 赛道 | 基础模型 + 通用助手 |
| 客户类型 | B2C + 订阅 |
| 收入模式 | 订阅（SuperGrok / X Premium+） |
| 收入 | 2025 约 **$350M**（估算）；季度：Q1'25 $52M → Q4'25 $144M → **Q1'26 $298M** |
| 用户 | 64M MAU（2025 Q4，含 X 内使用） |
| 定价 | SuperGrok $30/月、SuperGrok Heavy $300/月、X Premium+ $40/月 |
| 成本结构 | 基础设施与训练支出约 **$1B/月**；Grok 4 单模型算力成本约 $500M |
| 估值 / 融资 | 估值 $250B（2026-02）；2026-01 与 SpaceX 合并，合并后估值 $1.25T；累计融资 $42B |
| 增长引擎 | **X 平台免费引流**（4 亿 X 活跃用户），几乎零营销成本 |
| 护城河 | X 的独有语料 + 免费分发渠道 |
| 关键洞察 | 收入 <$1B，却拿了 $42B 融资。这是**「分发即护城河」**的典型案例——不需要买量，因为母体平台自带数亿用户。同时说明 AI 助手赛道的估值与收入严重脱钩。 |
| 可信度 | C（收入为媒体估算） |

## Google Gemini

| 项 | 内容 |
| --- | --- |
| 赛道 | 通用助手 |
| 客户类型 | B2C（订阅包裹在 Google One / Workspace 中） |
| 收入模式 | 订阅 |
| 收入 | **$1.2B**（2025，仅订阅口径；2024 为 $0.3B） |
| 用户 | **750M** 活跃用户（2025 年底，含 AI Overviews 使用者） |
| 下载 | 430M+（2024-05 上线以来） |
| 分发 | 内嵌 Google 搜索（AI Overviews）+ 通过 Google 自有广告位推广；季度网页访问 1.28B（2025 Q4） |
| 关键洞察 | **750M 用户只换来 $1.2B 订阅收入**，说明捆绑与免费分发能极快地拉用户，但**转化率很低**。对比 ChatGPT 900M 周活换来 50M 付费订阅，Gemini 的变现效率更差，因为它把价值让渡给了搜索广告基本盘。 |
| 可信度 | B |

## Microsoft Copilot

| 项 | 内容 |
| --- | --- |
| 赛道 | 通用助手 + 生产力套件内嵌 |
| 客户类型 | B2B 为主（Windows / M365 用户） |
| 收入模式 | 订阅（捆绑在 M365 里，不单独披露） |
| 用户 | **218M** 活跃用户（2025，跨 Windows/app/网页；2023 为 28M） |
| 下载 | 88M+ |
| 投入 | 微软累计向 AI 投入 >$25B，其中 **$12.8B 投向 OpenAI** |
| 关键洞察 | **「AI 收入无法单独计量」的典型**——微软把 AI 收入混入云与数据部门，Nadella 表示期望 AI 成为最快达到 $10B run rate 的部门。这种「不单独披露」本身就是一种财务选择：既能讲增长故事，又不用接受 AI 业务的毛利审视。GitHub Copilot 是唯一有独立数据的子产品，订阅者 >1M。 |
| 可信度 | B |

## DeepSeek（反例：刻意不商业化）

| 项 | 内容 |
| --- | --- |
| 赛道 | 基础模型 + 助手 |
| 收入模式 | **无商业化**（开源 + 完全由对冲基金 High-Flyer 出资） |
| 用户 | 130M 活跃（2025 年底）；下载 173M |
| 关键成本数字 | DeepSeek V3 训练成本 **$5.5M**，据称仅为 GPT-4（>$100M）的 1/18<br>参数 671B / 14.8T tokens（对比 GPT-4 约 1T 参数 / 13T tokens） |
| 关键洞察 | 创始人梁文锋把每一代模型开源，**未承诺任何商业化路径**。这反而降低了监管绑定风险，并直接把中国市场的模型价格打下来（字节、腾讯、百度、阿里被迫跟进降价）。**它不是盈利案例，但是理解「AI 定价权」必须看的案例**——一个不追求收入的玩家，会把全行业的价格天花板压低。 |
| 可信度 | A/B |

## 横向对比：谁真的赚钱？

| 公司 | 收入（可比口径尽量对齐） | 毛利率 | 是否盈利 | 备注 |
| --- | --- | --- | --- | --- |
| OpenAI | $40B 年化（2026-07） | 33% | 否，2030 才转正 | 规模最大，但毛利被推理成本吃掉 |
| Anthropic | 口径冲突（$6B ~ $65B） | 未披露 | 未披露 | 企业占比高，ARPU 高 |
| xAI | <$1B | 未披露 | 否 | 靠 X 免费分发 |
| Google | $1.2B（订阅口径） | 未披露 | 未知 | 750M 用户，转化低 |
| Microsoft | 未单独披露 | 未披露 | 未知 | 财务上不可见 |
| DeepSeek | 无 | — | — | 刻意不商业化 |

**结论：截至 2026 年，基础模型层的通用助手业务没有一家被公开证实为「规模化盈利」。** 真正的盈利案例出现在应用层与垂直层（见其他案例文件）。
