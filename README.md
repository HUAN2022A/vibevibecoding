**覆盖范围**：24 个公司/产品案例，6 大板块，6 种收入模式；结构化数据表 28 条记录（含子产品与同一创作者的多条产品线）。

**几条核心结论**（详见 `patterns.md`）：

- 截至 2026 年，**基础模型层的通用助手业务没有任何一家被公开证实规模化盈利**
- 垂直 AI 公司不应自研垂直模型，护城河在工作流、数据与内容授权（Harvey 主动砍掉自研模型）
- 用户数下降、收入可以上涨（FaceApp：用户 -60%，收入 +6 倍）
- 免费用户转化率普遍低于 6%；独立开发者的经验值是免费与付费用户价值差约 1,000 倍
- 个人用户亏钱、企业用户赚钱是可接受的常态（Cursor 明确披露）

> ⚠️ 数据基准日 **2026-09-14**。私募公司收入数字多为估算，存在口径冲突（尤其 Anthropic），引用前请先读 `sources.md` 的待核实清单。
